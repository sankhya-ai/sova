01 / THE METHOD

Green is a color.
Not a guarantee.

A test can pass and still miss the bug.
Start with the behavior. Then challenge the test.

01

Plan the cases.

A planning skill your agent can load. Map screens, roles and expected outcomes before driving a flow.

skill-planning/
02

Keep the tests.

Recorded web flows become plain Playwright tests. They live in your repo, beside the code they check.

sova check
03

Break the app.

Deliberately change validation, permissions or calculations. See which test catches each break. And which misses it.

sova mutate
↳

One run. No retries. Use --repeat to vet new tests for stability, not to hide a failure.
